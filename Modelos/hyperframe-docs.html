O que é o HyperFrame?
📄
HTML + CSS + JS
Sua animação web
→
🎬
HyperFrame
Puppeteer + FFmpeg
→
🎥
MP4 (H.264)
1920×1080 @ 30fps
Em vez de gravar a tela em tempo real, o HyperFrame avança o tempo virtualmente, frame a frame, captura screenshots e encoda em vídeo de alta qualidade.
Pipeline de Renderização
1
Resolver Cena
URL remota, arquivo .html ou pasta — tudo aceito
scene-loader.ts → loadScene()
🔗
2
Ler Metadados
Lê window.hyperframe (fps, frames, resolução) via Puppeteer
renderer.ts → readSceneMetadata()
📋
3
Dividir Carga
Distribui frames entre workers paralelos (worker_threads)
partition.ts → partitionFrames()
⚡
4
Capturar Frames
Para cada frame: setFrame(n) → screenshot PNG
renderer.ts → renderFrames()
📸
5
Encodar MP4
FFmpeg: PNGs → H.264/AAC, CRF 18, yuv420p, faststart
encoder.ts → encodeVideo()
🎞️
API window.setFrame

window.hyperframe

Declara os metadados da cena: fps, total de frames e resolução.

window.hyperframe = {
  fps: 30,
  durationInFrames: 900, // 30s
  width: 1920,
  height: 1080
};

window.setFrame(n)

Chamado para cada frame. Atualiza o DOM baseado no índice n.

window.setFrame = function(n) {
  const t = n / 30; // segundos
  el.style.left = (t * 200) + 'px';
};

window.hyperframeReady

Promise aguardada antes do render. Use para pré-carregar imagens e fontes.

window.hyperframeReady = new Promise(res => {
  const img = new Image();
  img.onload = res;
  img.src = 'https://cdn.../img.png';
});

Shim Automático

Cenas sem setFrame recebem um shim que virtualiza Date.now, rAF e timers.

// html-adapter.ts injeta automaticamente:
Date.now() → relógio virtual
requestAnimationFrame → fila virtual
setTimeout/setInterval → timers virtuais

Como Usar

⌨️ Via CLI render

# Build do projeto
npm run build

# Renderizar cena local
node dist/cli/index.js render \
  Modelos/cena.html \
  -o output/video.mp4

# Com opções
node dist/cli/index.js render cena.html \
  --fps 30 --width 1920 --height 1080

🌐 Via API serve

# Iniciar servidor
node dist/cli/index.js serve

# Submeter job
curl -X POST localhost:3002/jobs \
  -F "scene=@cena.html" \
  -F 'config={"fps":30,...}'

# Monitorar
curl localhost:3002/jobs/<id>

📄 Cena Mínima

window.hyperframe = {
  fps: 30, durationInFrames: 90,
  width: 1920, height: 1080
};

window.setFrame = function(n) {
  const t = n / 30;
  el.style.opacity = t / 3;
};

📤 Upload via Node.js

// upload-job.js
const config = {
  fps: 30, durationInFrames: 900,
  width: 1920, height: 1080,
  concurrency: 1,
  outputPath: 'output/video.mp4'
};
// Multipart POST → STATUS 202
